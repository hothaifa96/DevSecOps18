# Docker Labs 

## lab I

clone this repo and try to build the image and start a container 
```bash
git clone https://github.com/devopsPRO27/Docker-exercise-1
```
Your task is to create a Dockerfile that:
- Uses an appropriate Python base image
- Copies the application files
- Sets up the Python environment NAME
- Runs the application when the container starts
